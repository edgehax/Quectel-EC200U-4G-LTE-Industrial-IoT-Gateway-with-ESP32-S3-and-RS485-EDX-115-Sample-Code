- **Radio:** Quectel EC200U-xx 4G/LTE BIS CAT1 Module
- **MCU:** Espressif ESP32 S3 MCU
- **Memory:** 16MB Flash and 8MB PSRAM
- **USB Ports:** Two Type-C Ports UART / USB
- **Software:** ESP-IDF, Arduino, microPython
